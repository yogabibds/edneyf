# Instituto Edney Fernandes — Site

Site institucional premium com copy, imagens conceituais, estatísticas, CTAs e animações modernas.

## Publicar
Suba a pasta completa em Netlify, Vercel ou hospedagem estática.

## Segurança editorial
Evitei publicar endereço exato, orçamento detalhado, contratos, plantas técnicas completas e informações jurídicas. O site apresenta visão, impacto, pilares e renders conceituais.

## Antes de publicar oficialmente
Validar estatísticas e fontes; substituir e-mail de contato; registrar domínio e marca.
